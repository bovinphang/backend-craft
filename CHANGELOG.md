## [1.0.0] - 2026-11-09

Backend 1.0.0 was published on 2026-11-09 (Asia/Shanghai), using common 2.0.0.

### Added

- 21 service-domain entries, 8 agents and 8 command workflows, with English and Simplified Chinese resources. Five framework specialties cover Spring Boot, FastAPI, Gin, Axum and Drogon.
- Complete delivery of 21 shared entries from the exact `@bovinphang/craft-common@2.0.0` dependency. Seven language foundations, including independent C/C++ entries, are shared across library, CLI, desktop and service roles; the existing backend validation projection keeps its six-language contract.
- Shared installation planning, ownership, version/language/digest conflicts, transactional recovery, read-only migration checks and task-scoped inspection. Existing edits and unknown files are preserved; no-Skill hosts receive private reference material.
- Conditional service engineering decisions and isolated real-framework examples, plus an HTTP idempotency example for commit-before-response failure, changed intent and concurrent replay. The latter is process-local memory evidence, not durable/distributed exactly-once or authentication.
- Existing-tool validation planning/execution and complete CLI, native OpenClaw and standalone-skill distribution. Hooks remain read-only by default; optional mutation/formatting requires explicit configuration.

### Changed

- Promote the shared dependency from the local development candidate to final version number 2.0.0 and regenerate bilingual snapshots/provenance from the same verified archive used by frontend 3.0.0.
- Synchronize current documentation and release prerequisites. Both product versions are published. Public-registry installation, complete regression testing and native-host activation remain separate verification activities.

See [coexistence and migration](docs/coexistence.md) and the [release gates](docs/verification/release-gates.md). Earlier dated verification reports describe their original artifacts and are not rewritten as new release results.
