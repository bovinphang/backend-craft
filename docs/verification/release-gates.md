# 发布前门禁

当前仅完成本地实现和验证，没有执行 Git 集成或 npm 发布。用户已确认使用精确 common 1.0.1；不能回退版本、改成本地路径依赖或添加供应链例外来伪造干净安装。

1. 审核并发布已验证的 common 1.0.1 归档，确认公开 npm 的 SRI 与两产品 lock 完全一致。最终候选归档和摘要随本地交付保留，发布时使用该实际归档。
2. 在现有供应链策略允许后，使用公开源执行两产品的 frozen 安装、check:common、lint、typecheck、完整测试和 pack:all。当前已实际尝试，因版本尚未出现在注册表而被拒绝。
3. 在具备 Cargo 的环境执行 Rust 微型工程真实缺陷/修复验收；本机不具备 Rust，因此不能声称六种本地工具链均通过。
4. 获得 Git 集成授权后推送并观察 Windows/Linux Node22 与六语言 CI；只有实际成功运行才能把“已配置”改为“CI 通过”。本次没有为触发 CI 擅自推送。
5. 选择 CLI 或对应原生插件渠道；两产品原生渠道不承诺公共发现去重。其余平台需要在宿主中确认资源刷新、信任与启用状态。
