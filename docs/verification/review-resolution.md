# 独立评审处置

独立上下文评审确认 6 项 Important、1 项 Minor，无已确认 Critical。全部重要项由主代理在同一修复轮执行，先观察对应回归失败，再修复；最终以完整套件验证，没有派出第二轮评审。原始报告保留于本地 reports/backend-craft/final-review.md，不把回归通过称为独立复审批准。

| 项 | 处置与实际证据 |
|---|---|
| I1 Windows 等价大小写路径挂起 | 平台路径等价判断及根终止保护；B/C 独立有界进程先超时，修复后正常；真实大写工作区通过公共协调器的 dry-run 也先 RED 再 GREEN |
| I2 全跳过测试误报通过 | 按驱动最终汇总排除 skipped/disabled/todo，JUnit 核对实际执行计数；真实 unittest、Node 全跳过与部分执行回归通过。隔离 node:test 内部进程标记，避免嵌入调用时递归跳过 |
| I3 子项目配置遗漏 | 先读取最近已识别工程配置，相对路径以配置目录解析；覆盖子目录、子文件、根显式多工程、根配置损坏但子工程有效 |
| I4 更新残留旧资源 | 每轮完整规划记录期望集合，未修改过期资源与共享片段同事务退役，用户修改保留并报告 partial；覆盖 dry-run、回滚、真实 prepared/committed 中断恢复及缺失入口不创建空文件 |
| I5 doctor 未检查共享入口 | 对文本 marker、JSON 路径/hook、TOML 条目按自身摘要检查；用户和前端其他正文变动不影响健康，后端片段缺失或修改不能报健康 |
| I6 Claude 原生市场缺少构建产物 | Git marketplace 精确指向完整 npm 来源；从无 dist、无 node_modules 的市场目录读取来源，再解包真实归档运行 Hook，确认执行文件随来源交付 |

M1 为延期轻微项：inspect 当前只报告工程证据，没有接入只读工具状态字段；可通过 validate --dry-run 获取缺工具信息。本期不声称该字段已交付。

评审设定之外的三项均明确保留边界：双原生插件公共发现去重不在范围；复用的既有大型图标/图表数据不逐条重新设计语义；宿主 UI 实际启用没有证据，继续显示 unknown。详见 [实施决策](decisions.md)。

公开精确依赖安装、Rust 实际编译/测试和远程 CI 是独立外部门禁；它们没有被本地套件或归档测试替代。
