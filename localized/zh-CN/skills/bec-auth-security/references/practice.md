# 服务端授权与安全

## 关键检查

1. 映射入口、可信身份、租户/对象边界及敏感操作，在每条访问路径区分认证与授权。

2. 从服务端验证的身份与权限推导授权上下文，不能仅相信客户端传入的租户/对象声明。

3. 查询和操作限定到已授权资源，覆盖批量、导出及后台路径；必要授权无法确认时拒绝。

4. 校验并限制输入，数据库操作参数化，按实际信任边界评估出站请求、文件及反序列化。

5. 凭据与原始敏感载荷不进入日志/报告；遵循最小权限，审查轮换、到期及撤销行为。

6. 测试未认证、错误对象/租户、已撤销权限及提权操作，分开报告已确认事实和未覆盖旁路。

## 边界与案例

适用场景：
- 修复服务端 API 租户隔离
- 在 JWT 校验后审查对象级授权
- 测试跨租户和越权负向路径
- 处理服务端密钥及不可信输入

相邻专项应按实际任务选择；纯前端 UI、图片生成和普通文案润色不在此范围。

## 交付要求

- 已读取的工程/契约证据及变更作用域。
- 选用方案、关键不变量、资源/错误或失败边界。
- 实际运行的命令与结果，未运行项及不能证明的结论。
- 兼容、恢复/回滚或后续处理限制；评审结论须给可核实位置。
